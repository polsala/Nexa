# Dependency investigation and licensing

Investigation date: 2026-09-14. Locked versions, rather than floating release candidates, are the build contract. Inspect package.json, pnpm-lock.yaml and Cargo.lock for exact transitive resolution. Generate the inventory with pnpm run licenses.

## Chosen runtime dependencies

Tauri 2 (MIT/Apache-2.0), React (MIT), TypeScript/Vite tooling (MIT), Tiptap/ProseMirror (MIT), individually selected Univer OSS 0.25.1 components (Apache-2.0), lucide-react (ISC), serde/serde_json/thiserror/tracing/UUID/base64/SHA-2 (permissive dual licenses as inventoried), zip 8.6, roxmltree 0.21 (MIT/Apache-2.0), csv (MIT/Unlicense), tempfile (MIT/Apache-2.0), imagesize 0.14 (MIT), notify (CC0). Each has one concrete role; no Node runtime is shipped. The browser-only ZIP adapter uses fflate (MIT).

The Univer umbrella package was removed because it installs unused Pro components. Only pinned OSS presets are selected and audited. The separate @univerjs/telemetry 0.25.1 dependency exports only a dependency-injection identifier: its source header is Apache-2.0, despite missing npm license metadata. It has no network or collection implementation, and no telemetry service is registered. No Pro, account, server, remote font or license key is required. Tiptap commercial extensions are not used.

The production audit identified Univer core's pinned nanoid 5.1.11 as affected by GHSA-28wg-ghj8-5hjv. A scoped pnpm override selects MIT nanoid 5.1.16, the same-major [upstream fix](https://github.com/ai/nanoid/releases/tag/5.1.16), instead of silently suppressing the advisory or migrating to the new major. Formula, clipboard and native workflow tests exercise the resulting engine graph. Run `pnpm audit --prod --audit-level high` before each release; a clean registry audit is not a security certification.

`@univerjs/docs-ui@0.25.1` has a small pnpm-managed focus guard for hidden/inert or detached editor hosts. Native WebKit regression traces demonstrated input loss from delayed background initialization despite the [documented auto-focus setting](https://docs.univer.ai/guides/sheets/features/core). See [ADR-003](../architecture/decisions/ADR-003-editor-engines.md), the checked-in patch and the native input tests. This is an Apache-2.0 source modification; keep its notice and recheck the patch on every engine upgrade.

Linux platform libraries include GTK, GLib and WebKitGTK with LGPL/BSD licenses and system codecs. These are dynamically linked OS dependencies, not relicensed Nexa source. AppImage redistribution must retain the bundled libraries' notices and corresponding source/relinking obligations; distributions provide their source packages. Windows WebView2 is an OS/runtime prerequisite under Microsoft's terms, not an embedded open-source Chromium distribution. Build-only Lightning CSS is MPL-2.0 and caniuse-lite data is CC-BY-4.0. No application code is derived from either.

## Office candidates evaluated

| Candidate                                                              | Evidence, read/write, maintenance and decision                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [docx-rs](https://docs.rs/crate/docx-rs/latest) 0.4.22                 | MIT. July 2026 release; DOCX reading/generation, examples and tests. Portable Rust. Does not eliminate the need for unknown-part preservation or layout mapping. A reasonable future adapter; not chosen as a lossless whole-package abstraction.                                                           |
| [ooxmlsdk](https://github.com/KaiserY/ooxmlsdk) 0.13                   | MIT/Apache-2.0. Active generated schema SDK, multi-format read/write and corpus tests. Large generated surface and integration/mapping cost. Portable Rust; no Microsoft runtime requirement. Retain as a possible replacement below our bounded ZIP boundary.                                              |
| [umya-spreadsheet](https://docs.rs/crate/umya-spreadsheet/latest) 3.1  | MIT. Recent releases; read/write/lazy-read, examples/tests and broad XLSX support. Portable Rust. Round-trip fidelity still requires testing our corpus; dependency and full-model cost are higher than the bounded initial mappings.                                                                       |
| [excelize-rs](https://docs.rs/crate/excelize-rs/latest) 0.1.9          | BSD-3-Clause. July 2026 release series, portable Rust port, read/write/formula and round-trip tests advertised. Distinct from the older xuri/excelize-rs repository; evaluate the exact crate provenance. Early release history and large crypto/image/statistics dependency graph were not justified here. |
| [OpenCalc](https://github.com/CasualOffice/opencalc)                   | Apache-2.0. Active Rust/WASM engine with import/export, formulas, fixtures and security limits. Upstream explicitly labels the SDK alpha/0.0.0. Substituting it would replace the working spreadsheet engine, not simply add a parser. Not adopted for this release.                                        |
| rust-pptx / [pptx](https://docs.rs/crate/pptx/latest/source/README.md) | The exact rust-pptx package could not be verified as a maintained stable read/write foundation. The separately named MIT pptx 0.1 advertises read/write and four dependencies, but has a very short release history. Do not confuse package names or infer mature round-trip coverage from a README.        |
| Owned zip + XML adapters                                               | Smaller supported surface, explicit bounded input, byte-level source preservation, tests for malicious XML, semantic goldens and independent converter checks. Tradeoff: fewer editable Office features. All third-party parsers stay behind office-io.                                                     |

No candidate's README claim constitutes a security audit or proof of Windows compatibility. Our CI compiles/tests the actual selected stack on Windows and Linux. Do not claim absence of vulnerabilities from a passing test suite. Run dependency audits before publishing, review advisories, retain lockfiles and avoid automatically accepting breaking engine upgrades.

## RustSec review — 2026-09-15

`cargo audit` 0.22.2 found the newly issued rustls TLS-handshake advisory in the optional updater dependency graph. Cargo.lock was advanced from 0.23.44 to patched 0.23.45 ([upstream advisory](https://github.com/rustls/rustls/security/advisories/GHSA-2mjx-qc3c-rqvc)). Default builds do not initialize that network/update path, but the feature's dependencies are patched too.

Seven informational findings remain in the Tauri 2 dependency graph: unmaintained `proc-macro-error` and five UNIC crates, plus `glib` 0.18's `VariantStrIter` soundness warning. Nexa does not directly call that iterator. These warnings are not suppressed in audit configuration; replacing GLib's API family underneath the pinned GTK3/Tauri stack is not a safe patch-level dependency substitution. Track upstream Tauri/GTK remediation and review reachability before public release. Do not describe this dependency graph as warning-free.
